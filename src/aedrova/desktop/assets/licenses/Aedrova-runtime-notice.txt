Aedrova bundles OpenAI Codex CLI 0.155.1 as a separate runtime. Its source is unmodified. macOS signatures may be replaced when Aedrova is packaged and signed. Original runtime: https://github.com/openai/codex/tree/rust-v0.155.1

Offline translation uses CTranslate2, SentencePiece, py3langid, subword-nmt and Sacremoses. Their licenses are included alongside this notice. Language data is distributed by Argos Translate (https://github.com/argosopentech/argospm-index). Selected downloaded model archives include their original README attribution and metadata in the device's Aedrova Translation directory. OPUS-derived models credit Jörg Tiedemann and Santhosh Thottingal, “OPUS-MT — Building open translation services for the World”, EAMT 2020, and retain the package's CC-BY 4.0 attribution. Aedrova does not alter the model weights. See each installed model's README for its applicable authorship and license.
